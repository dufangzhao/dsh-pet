## Verification and handoff

- Actual viewport, zoom and DPR; supported minimum-size/focus/motion observations.
- Shared-boundary verification and each option's UI reachability/state results.
- Real vs controlled-service/device evidence and remaining gaps.
- Working review entry, screenshots and implementation links; user's selected option if one exists.
