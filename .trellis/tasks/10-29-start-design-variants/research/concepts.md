# Start 五版概念（DeepSeek 设计总监视角）

结论：五个方向都成立，差别在信息层级与任务顺序，不在配色与圆角。本轮我落地 bench 与 switchboard 两版（文件已定，见文末），另外三版由 asset worker（stage、workspaces）与整合者（spine）并行写。专家报告只有一份真实返回（research/experts.md），本文不冒充共识；命名沿用那五个，内部结构与取舍是我自己的判断。

## 共同基线（五版都遵守，缺一版就不算同一件产品）

- **状态只有一个所有者**：`useApplication` / `useDemo` / `useModelConnection` / 主题记录仍由设置台持有；版式只摆放 `StartSlots`（status、vendors、connect、pet、theme），每个插槽在一次渲染里只出现一份。草稿（挑中哪家、模型名、Key）在 `context.draft` 上，换版式不丢、不重开麦克风、不重播轮询。
- **不摆 `slots.guide`**：「使用向导」已在 ConsoleApp 标题行，重复摆放就是第二颗按钮、第二条回执。
- **没有假连接**：`blankKeyAllowed` 只对「在用的那一个端点」放行留空；「已保存」不等于「测过」，测试只对 active 有意义。未接入的厂商芯片画得出但点不动，不给它编一个可用状态。
- **只用 `--pk-*` 令牌**：`--pk-bg/surface/sunken/text/muted/border/border-strong/accent/accent-soft/accent-text/accent-on/ok/danger/warn/ring/shadow-1/radius/radius-lg/transition/font-mono/gutter`。不写死色值，深色与浅色由令牌本身走，减少动画读 `context.app.values.reducedMotion` 再交给 `LabIcon`。
- **一套图形语言**：整合者的 `lab-icons.tsx`——24 格、1.6 描边、圆头圆角，morphicons 2.0.2 只做**真实状态之间**的形变（回应/暂停、在桌面上/已隐藏、预览日/夜、话筒/停止）。变体作者不各自造图标，也不给静止的东西加动画。
- **不加后台不存在的东西**：没有指标、没有图表、没有"最近使用"、没有假的连接历史条目。
- **去色检验**：把五版的颜色全部换成同一种灰、边框同宽、圆角相同，仍然能一眼分辨——因为分辨靠的是栏宽、栏数、首屏主角、DOM/焦点顺序与折叠层级（每版末尾写清那条结构线索）。

## 一、bench「并肩工作台」

- **谁在用**：**林嘉禾**，高校教务老师，双屏显示器，一天里设置台开着当"副屏工具窗"，主屏在表格里。她要的是接线的时候眼角能看见那只猫在不在，而不是先读完一段说明再去滚。
- **主要情景**：日常平衡。多数时候只是确认「还在桌面上、还连着」，偶尔换一家模型。
- **1200×800 栅格**：正文轨道 848 = **464 桌宠舞台 + 24 + 360 连接检查器**，两栏顶对齐；配色工作室在下方整宽（464+24+360 同轨）。左栏是主角：预览（说一句/录音/日夜/菜单/拖动/点按）+ 三颗原生动作（在桌面隐藏 / 在桌面显示 / 装扮）；右栏是窄检查器：连接一句话与「测试连接」→ 厂商芯片 → 模型 / Key / 保存并开始 → 申请 Key 与平台切换。检查器里的表单**纵向排**：模型 240 基准宽失效（360 放不下三件套），模型与 Key 各占一列、Key 提示换行不截断。
- **880×600**：上下堆叠——检查器在上（任务优先），舞台在下、仍保持 `min-height:260` 不被压扁；配色再往下。DOM 顺序与视觉顺序一致，所以键盘不用回头。
- **渐进披露**：不折叠任何东西——这一版的立场是"一眼看全"。长回执（失败原因、测试结果）在 360 栏内换行，绝不把「测试连接」挤出视线。
- **焦点顺序**：连接状态一句话 → 测试连接 → 15 家芯片 → 模型 → Key → 保存并开始 → 申请 Key → 平台切换 → 管理模型扩展 → 舞台工具（说一句/录音/日夜/菜单）→ 隐藏/显示/装扮 → 配色工作室。
- **取舍**：正文列被压到 464，配色工作室和表单都在同一个滚动列里；换模型的动线比 switchboard 长一步。换来的是"接线与陪伴同屏"，不用在两件事之间切注意力。
- **状态行为**：读到快照前舞台与检查器各说各的"还没读到"，不猜；没接模型时右栏保持完整可用（离线演示本来就靠得住）；保存失败与测试失败分别显示在保存/测试那颗旁边，不合并成一条绿色成功；`paused` 时录音工具直接说"桌宠已暂停"；原生桌宠隐藏后预览照旧能用（隐藏不等于销毁）。

## 二、switchboard「模型接线台」

- **谁在用**：**郑明远**，独立开发者，手上三个 Key 分属三家，一周里要来回换两次供应商、切一次国内/国际平台。他抱怨的是"每次都要在那堆芯片里重新找"。
- **主要情景**：高频接线与对比。桌宠是这页的**结果**（接好之后确认它活着），不是入口。
- **1200×800 栅格**：轨道 848 = 顶部 56 状态条（整宽）+ 其下 **184 服务目录 + 24 + 640 详情**；配色工作室在轨道下方整宽。左列是常驻**目录栏**：把共享的 15 家芯片改成竖排（`flex-direction: column`，只摆位置不改控件），在用的那家高亮、未接入的仍点不动；目录是一个可折叠的真 disclosure（`aria-expanded` + `aria-controls`），默认展开。右列 640 只伺候挑中的这家：表单在上（模型/Key/保存并开始横向排得下，恢复 240 基准宽），预览在下限高 260——比 bench 小一号，位置在表单之后，视线顺序就是动线。
- **880×600**：目录折叠成整宽一条（标题旁显示真实分组数"15 家"），展开后是横排芯片；详情整宽、预览回到 260 起跳；配色在最下。
- **渐进披露**：目录栏的折叠是唯一的隐藏层级，且默认展开——不为省高度把 15 家收进下拉。平台切换（国内/国际）留在详情里那一句真链接，不变成第二个目录项。
- **焦点顺序**：状态条的一句话 → 测试连接 → 目录折叠键 → 15 家芯片 → 模型 → Key → 保存并开始 → 申请 Key → 平台切换 → 管理模型扩展 → 预览工具 → 隐藏/显示/装扮 → 配色工作室。
- **取舍**：桌宠退到详情下方，第一眼不在它身上；目录常驻占掉 184，正文比 baseline 少约 90。换来的是"下次换供应商时不用重新扫一遍芯片海"——目录的位置记忆比图标更省时间。
- **状态行为**：目录的高亮只说"挑中的这家"，不等于"已连接"；已连接那一句话只在状态条里出现，两处用不同文案，避免把草稿读成事实。快照为空时目录与详情都显示"还没读到"，不给目录画假条目；`credentialStorageAvailable=false` 时 Key 输入框保持禁用与原文说明；浏览器登录那一家由共享表单自己换成"登录并连接/取消"，目录与状态条不重复播报。

## 三、spine「从连接到见面」

- **谁在用**：**苏晓岚**，第一次装，从群里链接下载完就打开设置台，不知道"模型"和"桌宠"是什么关系。
- **主要情景**：首用与教学式顺序，但不硬门控、不自动推进。
- **栅格**：一条竖脊（左边一条 1px 主线 + 三个结），三段各占整宽：接上模型 / 到见面 / 调颜色。1200 与 880 都是单列，880 时段的副文案收起来、标题与状态仍在。
- **控件位置**：每段头部 = 序号 + 真实状态图标 + 一个可重开的标题按钮（`aria-expanded`）；段体放对应插槽；配色段默认收起但不锁。
- **渐进披露**：三段独立开合；没接模型也能展开后两段（离线演示可用）；收起一段不替用户决定下一段该开。
- **焦点顺序**：段一标题 → 段一内容 → 段二标题 → 段二内容 → 段三标题 → 段三内容。
- **取舍**：一次只专注一件事，代价是重复编辑要反复展开；"序号"是真的动线（先接后见），不是装饰性 01/02/03。
- **状态行为**：段头的图标读真来源（回应/暂停、在桌面上/已隐藏、当前配色日/夜），配色那盏灯读主题记录本身；展开状态是呈现局部状态，换版式回默认，不写任何数据。

## 四、stage「桌宠在场」

- **谁在用**：**何舟**，把桌宠当陪伴，打开设置台第一眼看的是它今天什么表情，配色和模型是"给它换衣服、给它接脑子"。
- **主要情景**：身份优先。
- **栅格**：约 400 整宽舞台（预览 min-height 从 260 长到 400），原生动作（隐藏/显示/装扮）紧贴舞台下沿；再往下是两层**同流 tray**（接线、配色），不是遮住桌宠的 overlay；880 时舞台回到 260 起跳、tray 顺序不变。
- **控件位置**：舞台上方一行真实在场状态（在桌面上/已隐藏 + 回应/暂停的图标）；tray 头是"接上脑子""调一下颜色"，展开后放对应插槽。
- **渐进披露**：tray 的展开只影响可见性，不影响任何状态归属；预览的本地日夜灯不写全局主题（与既有语义一致）。
- **焦点顺序**：在场状态 → 隐藏/显示/装扮 → 接线 tray 头 →（展开后）状态条 → 芯片 → 模型/Key/保存 → 配色 tray 头 → 配色工作室。
- **取舍**：模型表单不在首屏，接线要多一次点击与一段滚动；换来的是这页真正像"我的桌宠"而不是像后台设置。
- **状态行为**：没接模型时舞台仍在说"待命，等你开始"，tray 头写"还没接上脑子"这种真实状态，不假装成功；原生隐藏后舞台继续可用（本地预览），但"在桌面显示"仍读真实窗口状态。

## 五、workspaces「三页工作簿」

- **谁在用**：**吴清和**，13 寸笔记本、经常只开 880 宽，一边开会被一边改一项，最烦一屏塞三件事。
- **主要情景**：最小窗格与专注一次一件事。
- **栅格**：顶部一条**真实状态条**（整宽，约 48：已连接的那家 + 测试连接 + 在桌面上/已隐藏 + 回应/暂停），其下三个本地页签各占整宽：接线 / 见面 / 配色。880×600 时状态条不折成两行，正文只剩当前一页，滚动距离最短。
- **控件位置**：页签是 `role=tablist` 的真按钮（左右键可换页），面板标题与状态条同源；「管理模型扩展」「语音输入」这两个跳转留在接线页底部，不在三处重复。
- **渐进披露**：一次只呈现一页；**不改 URL/hash**（换页是 React 状态）；配色页离开时按既有语义撤未保存试色；录音会话在切页时不中断（同一个 owner）。
- **焦点顺序**：状态条（含测试连接）→ 三个页签（aria-selected）→ 当前页内容 → 回到页签可左右移动。
- **取舍**：同一屏看不全三件事，任何跨页对照多一次点击；换来的是 880×600 下每页都有完整正文宽度和最短滚动路径。
- **状态行为**：状态条是唯一事实来源，页签标题里不再重复"已连接"这类话；没读到快照时页签仍可进（内容自己说"还没读到"），不做假禁用；暂停时见面页的录音工具说明原因。

## 素材采用（条件性，依 assets.md 与 asset-notices.txt）

- **图标语言**：morphicons 2.0.2（MIT）作形变引擎，24 格 / 1.6 描边 / 圆头，统一由整合者的 `lab-icons.tsx` 提供；只在四处真实状态用上（回应/暂停、桌面上/已隐藏、日/夜、话筒/停止）。厂商标记仍用 manifest 自带的 22px 白底方形（已在共享芯片里），不动它也不重新导出。
- **Uiverse 三个控件**（`alexruix/silent-otter-72`、`Maximinodotpy/thin-sheep-13`、`cssbuttons-io/wonderful-baboon-62`，各自 MIT）：只采纳"可供性"的一层——开关 thumb 与图标同进的过渡、输入框聚焦时标签上浮的动线、主按钮的按压回弹——全部改写到 `--pk-*` 令牌上，不搬固定色值与阴影，不引入 `Segoe UI` 自带字体族。
- **未采纳**：Space74 `lovely-goose-53`（离屏输入 hack + 固定绿）、Rich 的重阴影开关；理由记在 assets.md。
- 采用状态：**conditional**（许可与来源已核，实装时只用受作用域限制的 class，随 lab.css/变体 css 落进包内；`react` 为可选 peer，无额外运行时依赖）。

## 我这两版的实现边界（不等素材细节，先把结构与样式做实）

- `apps/desktop/src/renderer/console/start-designs/variants/bench.tsx` + `bench.css`，导出 `BENCH_DESIGN`。
- `…/variants/switchboard.tsx` + `switchboard.css`，导出 `SWITCHBOARD_DESIGN`。
- 两版都只从 `../catalog.js` 取 `START_DESIGN_METAS`（不碰 registry，避免 registry ↔ 变体循环）；`render()` 只返回真组件，需要 `useState` 的呈现状态住在那个组件里（不在普通 render 方法里调 hook）。
- 不写 registry / ConsoleApp / main / preload / 其他页 / build / 原生验收 / 提交；注册由整合者统一加行。
- 对共享插槽只做**摆放级**覆盖（栏宽、flex-direction、换行、间距），不改它的色、字号与语义；因此两版都依赖 `start-catalog / start-chipline / start-fields / start-actions / start-links / start-petline / start-status` 这些既有 class 名——若整合者后续重命名这些 class，需要同步这两份 css（这一点已写在这里，不另开兜底）。
- 880×600 两版都要求：焦点顺序与视觉顺序一致、长回执换行不挤掉按钮、预览不低于 260、配色工作室可完整进入。
