# Design boundaries

Current design and motion decisions are maintained in [the canonical design note](../../../../../docs/pet-bubble-design.md). The desktop extends its existing allow preset/source-registration path rather than adding a permission subsystem. UI preserves the same conversation, capture, media, task and saved-theme owners.

The first DeepSeek Qoder route returned no design and was stopped. The advertised DeepSeek-Flash CN route (qoder-cn/dfmodel,max) returned parameter recommendations based on the supplied geometry description, without source or screenshot review. The Frontend Developer applied those constants to its independent implementation; no reference product code/assets were copied. Native pixel and behavior evidence is [stored here](../../../../../qa/pet-bubble-replica/README.md).
