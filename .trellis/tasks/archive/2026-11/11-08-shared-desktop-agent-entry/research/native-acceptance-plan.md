Connection in this baseline is through the real console preload API, so it is **not** console form or end-to-end user-flow evidence. The targeted DOM case uses the real form and an in-flight target change, as described below. Exit 0 means only the selected subset passed. Temporary service data is retained for inspection; no existing data is removed.
- [display.mjs](../../../../qa/fixtures/companion-desktop/display.mjs) uses the provisioned private Xvfb via proot with exactly the `xkbcomp` bind, the private XKB directory, `-displayfd`, and `-nolisten tcp`. [DesktopHost](../../../../apps/desktop/src/main/desktop-host.ts) selects the actual platform and discovers the [Linux-declared source](../../../../plugins/companion-client/plugin.json); its existing permission kernel/config/supervisor remain authoritative. ## Full acceptance implementation after freeze

The prepared [connection form case](../../../../qa/fixtures/companion-desktop/connection-dom.mjs) drives revision 1 → own commit 2 → same-address new token at revision 2 → external Config CAS to revision 3, checks for false external-change alerts, preserves the address draft, and checks token clearance during an in-flight request, on page close and on retarget. The [target case](../../../../qa/fixtures/companion-desktop/target-dom.mjs) holds the real A send receipt after service serialization, switches through the real console IPC to a distinct service B, checks that the old draft remains, and sends a new B message via the real DOM while correlating both services' route counts and durable messages. The `--dom` subset passed on BUILD0, as recorded below; it does not prove that B was adopted before the old A handler settled.

An exact check that a successful receipt survives an additional failing `getState` cannot be induced through the HTTP proxy: the current production `getState` is a local IPC read. Nor does an ordinary DOM click retain a previous React render's handler after the new render commits. The existing hook regressions cover those controlled timings; no frozen bridge or Main handler is replaced to claim native evidence. If a saved actual React handler is separately exercised in Electron, label it controlled handler integration rather than ordinary DOM clicking. Likewise, absence of the token field while HTTP is held establishes clearance in flight, not the exact ordering of the JavaScript state update versus IPC dispatch. Source inspection and the hook/form tests provide separate evidence for dispatch ordering until a legitimate observation point exists.

Use actual rendered DOM controls for user actions. Main bridge reads may corroborate canonical IDs and authority, but cannot replace UI actions. Resolve selectors from the frozen renderer, not speculative names. Retain randomized titles/command IDs and capture the exact service receipts and snapshots; responses carry no token in reports. Service `POST /api/tasks` is an operator fixture control, not a desktop user feature.
