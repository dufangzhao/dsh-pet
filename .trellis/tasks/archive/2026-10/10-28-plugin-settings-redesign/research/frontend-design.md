# 设置台视觉与五页结构方案 v2（含用户修订；仅设计，不实现）

最终协调核对：以当前 PRD、design.md 和 visual-direction.md 的 Cortico/桌宠优先方案为准；气泡直接完成配置，提示词生效状态按后端确认。

结论：保留 v1 的两条纪律——色只取现有 ui-kit 令牌、骨架是 236px 安静侧栏 + 居中 ≤1120px 舞台。本轮改三件事：① 「习惯」改名 **人设**，完整提示词正文与真实环境段同页可见可编辑；② **对话** 不再是独立会话，而是同一只日常桌宠那份记录的视图，含真实非文字互动事件；③ 初始化、选模型、人设、更新通知尽量由桌宠气泡一步一步讲，给出可点选项，设置台是同一份状态的集中查看与编辑。Cortico 底层复用由父会话调查，本文不涉及实现依赖。

## 1. 色（5 个，取自现有令牌，与 v1 一致）

| 名 | 令牌 | 浅 / 深 | 用途 |
| --- | --- | --- | --- |
| 纸 | --pk-bg | #ffffff / #15171c | 内容底、输入底 |
| 静 | --pk-surface | #f7f8fa / #1b1e24 | 侧栏、预览台（比纸低半格，靠色差不靠边框） |
| 墨 | --pk-text | #1b1f26 / #e6e9ee | 正文；辅助字 --pk-muted #55606e / #a8b1bd |
| 群青 | --pk-accent | #2b52bb / #3f68d4 | 唯一强调：当前项竖线、主按钮、选中值 |
| 细线 | --pk-border | #e2e5ea / #2b2f37 | 只做行分隔，不做卡片描边 |

ok/warn/danger 只出现在徽标与提示条。角色的 --pet-body-top / --pet-body-bottom / --pet-face / --pet-halo 仍是全场唯一第二色族，也就是「配色」这项设置本身。

## 2. Windows 中文排印（不变）

- 一族到底，不联网取字体：system-ui → Segoe UI → Microsoft YaHei → PingFang SC。
- 层级只靠字号、字重、留白：页标题 26px/600/-0.01em；行标签 14px/600；说明 13px；时间与计数 12–13px tabular-nums。
- 中文专项：正文行高 1.6、line-break: strict、text-wrap: pretty、最小 12px、中英文与数字间一个半角空格、字距恒为 0。

## 3. 骨架（不变）

236px 侧栏：开始 / 人设 / 装扮 / 对话 / 语音输入，下面安静两项 扩展 / 关于，页脚是主题段控。内容居中 ≤1120px、左右各 40px；行标签左对齐 14px/600，值与控件右端对齐同一 260px 轨，行之间用细线而不是卡片；预览舞台 440×380 与行并排，1180px 以下退成页顶 260px 横条。760×560 最小窗口不隐藏内容、无横向滚动。

标签：**现有** = 已被真实桥接支持；**本轮** = 消费者由后端本轮补齐的计划联动；两者之外一律不画控件。

### 开始（R2）
```
开始 —— 先看一眼，再决定接不接
+- 连接 --------------------+ +- 预览舞台 --+
| 现在怎么回复 [离线脚本演示] 改 | |  真角色 152px |
| DeepSeek    ○ 未接入（可选）   | | 桌面就是这一只 |
|   [填入我的 Key]        已保存  | |   [正在空闲]  |
| 本机识别   [实际模型就绪状态]     | +---------------+
+----------------------------+
第一步不用 Key：现在就对它说一句话【现有】  [去对话]
应用运行中 · 没有正在运行的任务        [停止全部任务]
```
两个真实来源（离线脚本 / DeepSeek BYOK），没有厂商芯片墙。**第一轮没有 Key 也能走完整流程**：回复来源默认离线脚本，能否发送与 Key 无关，Key 只是可选的第二步；界面不许把「没接 DeepSeek」写成未完成。

### 人设（R3，原「习惯」）
```
人设 —— 它怎么称呼你、按什么说话
回复语言    [下拉：简体中文]   它的回复使用这种语言
称呼你      [输入：主人]        它的名字 [输入：小蓝]
说话风格    ● 安静  ○ 默认  ○ 活泼      说完自动发送 [开关]【现有】
─────────────────────────────────────
它的完整提示词                  [已保存 · 等待当前处理结束后生效]
┌ 人设正文（可编辑：存下来真的会用它回复）┐
│ 你是小蓝，称呼用户为「主人」……          │
│                         [保存正文]      │
└────────────────────────────────────────┘
┌ 运行环境段（只读，每次由它自己填）      ┐
│ 现在是 17:02 · 今天还没有对话记录        │
└────────────────────────────────────────┘
```
「完整提示词全文」包括可编辑人设正文与实际注入的完整环境/工具段，分段和真正发出的内容一致。经统一配置校验保存后请求 Cortico 安全边界重载；分别显示已保存、待生效、已生效或应用失败，收到 applied 确认后才称当前生效。正文草稿在冲突/失败时保留。

### 装扮（R3）
```
装扮                       + 预览舞台 +
桌面形态  ○ 简约  ● 圆头    |  ← 立刻跟着变 |
配色     ● 晨蓝  ○ 雪青     |  [正在空闲]   |
         ○ 松墨  ○ 柿橙     +--------------+
在桌面显示桌宠      [开关]
```
形态与配色是同一 SVG 骨架上的一个类 + 四个 --pet-* 变量【本轮：主进程把同一份值同时喂预览与桌面窗，预览与桌面天然一致；换形态不改外接矩形，命中区照旧】。「在桌面显示桌宠」【现有】走插件启停，宿主真的显隐窗口；文案不出现「插件」二字。

### 对话（R4，同一份互动的记录视图）
```
对话 —— 今天它和你都做了什么             [清空记录]
16:11  动作   你戳了它一下                    [脸红]
16:11  我说   现在几点了？
16:12  桌宠说 离线脚本演示：现在是……            [离线]
16:13  状态   录音结束，识别用了 1.4 秒
现在   录音中 · 剩余 20 秒  [结束并识别] [取消这次]
[对它说…]                                              [发送]
```
它只是那份日常互动记录的视图，不是第二个会话：同一条时间线、同一份记录，动作只是新增一种条目类型，**不新建历史、不新建聊天入口**。消息 / 流中文本 / 阶段 / 录音控制 / 清空【现有】；非文字互动事件（戳一戳、摸头、随之而来的脸红这类角色状态）写入同一条时间线【本轮】。宿主没有报来的事件种类不显示，也不拼出假的互动次数统计。

## 4. 统一互动时间线样式（对话页与预览台共用）

- 一行一个事件：`时间(12px tabular) · 类型词(小字) · 正文(14px) · 右侧来源或状态徽标`，细线分隔；不画气泡尾巴、不做左右两栏的聊天气泡墙——那套语法和行式设置台打架。
- 类型词固定四个：我说 / 桌宠说 / 动作 / 状态。含义靠文字，颜色只做辅助；离线回复必须带「离线」徽标。
- 长文换行不截断，正文 ≤68ch；正在流出的文本走 aria-live，不弹提示。
- 预览台顶部那一行复用同一语法（时间戳换成实况状态），所以「桌面上发生的事」与「对话页记录的事」是同一句话的两种出现位置。

## 5. 桌宠优先：引导、气泡选项、更新与稍后 / 重试

- 引导由桌宠气泡一步一步说明，并在气泡内提供可点击选项、普通输入或掩码 Key 输入，直接调用与设置台相同的后端校验、保存并展示真实结果。用户无需先打开设置台。步骤由实际流程决定，提供稍后、取消、重试和恢复；没 Key 也能完成本地配置引导，离线脚本体验明确标注。
- 设置台是同份状态的集中查看/编辑入口，气泡可以直接改值与完成配置；两处共用一份后端配置和引导进度。长提示词可以展开到人设页编辑，普通选项不以跳转为必经步骤。
- 准备与更新共用一块进度条，只画宿主真的报上来的阶段；报不出数字时是一句话（正在准备识别模型），不是假百分比。三种收尾固定：完成 `已完成 [知道了]`、可推迟 `稍后`（下次启动再提醒一次，不静默取消）、失败 `这次没完成：<原因> [重试]`。【现有：阶段与失败原因来自宿主；本轮：更新通知本身没有来源，宿主报不出来时整块不出现】
- 跳过/稍后保留已成功保存的选择，可从桌宠或设置台恢复。未配置模型不伪造 AI 可用状态；本地引导与真实触碰仍可工作。

## 6. 保存 / 失败 / 空

- **保存与应用**：文字、人设正文和扩展表单保留草稿并显式保存，错误/冲突保留尝试值；小型选择可直接写入并按真实结果回显。提示词重载可能等待当前处理完成，不能把保存成功等同立即生效。
- **冲突**：沿用原文「这条配置已被别处改过，保存被拒绝；刷新后重新选一次。」不自动覆盖、不假装成功。
- **读不到**：三态外壳收起整页 → 空状态「状态不可用」+ 一句原因 + [重新读取]；桥缺失说明「请从桌宠的『设置』重新打开窗口」。
- **空**：对话页说明还没有日常互动记录，可以与桌宠说话或触碰它。桌面隐藏时预览仍显示当前选中的形态，提供显示桌宠操作；本地识别未准备好时指向实际可用配置，不假装存在自动下载。
- **失败**：一次失败只出现一处，贴在使用它的那一行下面，role=alert，说清哪一项、为什么、怎么办；不道歉、不含糊。

## 7. 不出现的技术字段

日常五页不出现：schema、JSON、revision、owner、generation、lease、摘要或哈希、运行时开关、任务 ID、capability 名、IPC 通道、调试清单。需要授权含义时用普通中文：「允许它使用麦克风」「这个来源你还没确认，确认后才能启用」。机器接口与审计仍在「扩展」「关于」，键盘可达但不占主视线。

## 8. 自评（对照截图与「只放用户功能」原则）

- **对得上**：236/1120 与色令牌原样保留；人设页把「完整提示词」拆成可编辑正文与只读环境段，正是用户能理解的两件事；对话页只做同一份记录的视图，没有第二个聊天入口；每一步都留着「没有 Key 也能走完」的退路。
- **最大风险**：人设页现在有四项（语言、称呼、名字、风格）连同正文消费者都靠本轮后端落地。任一没落地，那一行就不许出现在页上——顺序应为配置扩展 → 提示词装配 → 才画 UI，宁缺不假。
- **次风险**：互动事件（戳一戳、摸头、脸红）若宿主不能真的报出来，对话页退回纯文字时间线，并写明「动作记录还没有接入」，不能用现有消息拼出假动作。
- **我不满意的一处**：预览台与参考截图的深色点阵面板相像，已改成比纸低半格的浅面 + 一条地平线，彩色只由角色承担；参考图真正该学的是「值右端对齐同一轨」的扫读速度。行式时间线也牺牲了聊天气泡的亲切感，换来同一套语法能同时容纳文字与动作——这是本轮唯一我觉得可惜的取舍。
- **克制**：一处强调色、一处彩色实体、一处 0.16s 段控动画；无页头图标、无顶部分隔线、无卡片阴影。引导限制在四步，多出来的信息进设置台的行，不进气泡。
