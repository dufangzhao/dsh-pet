# Original desktop-pet controls

## Goal

Create a recognizable product of our own. The user rejected five layouts because they still reused the Coopanion-replica controls. Replace the actual presentation system, not only positions or palettes, while preserving proven functions and the five review layouts.

## Requirements

- DeepSeek max implements frontend. Native HTML/React with one coherent original control system, optionally drawing licensed material from the two specified sites. Keep Morphicons2.0.2 and original glyphs where useful.
- Redesign real buttons, text/Key inputs, provider picking, regions, status/error/pending feedback, disclosure/navigation, preview actions/composer, theme editor, and settings shell. No old capsule vendor rows, old segmented tracks, pk-button/Field/Section widgets or old preview floor/editor surfaces in the new Start presentation.
- Reuse behavior/controllers and the same Core/config/credentials/recording/history owners. Do not pass old rendered JSX slots into a new skin and call it an original control system.
- A compact original component/state board and explicit tokens tie all five layouts together. Replace reference builtin theme names/palettes; migrate builtin selections without losing custom schemes, saved preference mode, Key or history.
- Apply the new shared controls to normal Start and five review alternatives. Preserve the layout alternatives and all real actions; other page bodies are later scope, but the shared shell should carry our own identity.
- Update replicate-then-redesign so originality is checked at component/interaction/visual-language level. Keep native receipts truthful, and test actual component wiring.
