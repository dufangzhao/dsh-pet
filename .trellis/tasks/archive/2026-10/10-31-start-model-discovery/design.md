# Integration design

Reference evidence: Coopanion old llm-settings/panel.ts invokes models for the selected instance; current providers/detail.ts supplies unsaved entry/optional secret. Its Cortico server source is missing locally, so only use observed behavior and standard protocol facts. Reference clone stays read-only.

Add ModelCatalogResult{id,models:string[]} and ModelConnectionBridge.getModels({id,key?}) with fixed IPC and exact trusted-source/argument validation. URLs, owner and secret-key identifiers come only from MODEL_SERVICE_ENDPOINTS. Queries never call saveAndStart/test or change active provider/config revision.

Main uses existing TaskSupervisor.run for the LLM provider owner and obtains a network permission lease for its fixed origin. Existing CredentialBroker gains a small host-only borrow method using the single broker-owned lazy generation/session shared with the runtime (the former runtime client map is removed), with optional one-operation supplied secret; it reuses existing authorization/lifetime/redaction/result checks, never reissues a client or writes the supplied key. SDK and plugin runtime APIs remain unchanged. The controller enables/admission-checks the existing built-in when needed to obtain its owner/session; no agent capability selection changes.

A bounded model-catalog helper implements GET lists for OpenAI-compatible, Anthropic, Gemini and signed-in ChatGPT protocol shapes. Reject redirects and malformed responses; cap list length/IDs and pagination; return honest standard errors/empty result. One existing task deadline owns request cancellation.

Start owns the temporary selected-endpoint result and request generation. Pick/region/Key changes discard results and ignore old completions. Catalog does not persist or replace global provider metadata. UI exposes real results through the current model field/datalist and a fetch button; successful listing is not successful connection. Add a fixed selected-draft test IPC returning its target and probe outcome, using the same host task/network/credential path. Reuse one host-independent response/probe implementation shared with the built-in provider rather than create a second diagnostic protocol implementation. Reasoning effort is default/low/medium/high; absent legacy config means default, and each supported protocol must carry it to the actual request. The accepted offline style preview stays explicitly offline; any added example control there is labelled and not evidence of production functionality.
