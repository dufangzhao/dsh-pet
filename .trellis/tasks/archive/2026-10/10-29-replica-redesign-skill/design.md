# Design

Create .agents/skills/replicate-then-redesign/SKILL.md plus agents/openai.yaml and one optional evidence-template reference. Entry routes based on the actual current phase: inspect/replicate/verify/design-options/implement. Tool/model/site choices are conditional on user/environment; only exact adopted asset license and provenance are mandatory. No script is added unless this implementation demonstrates repeated deterministic work worth automating.
