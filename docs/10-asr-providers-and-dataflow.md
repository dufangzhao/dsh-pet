# ASR双路径与数据流规格 v0.1

状态：本地/云端首版双路径已确认（[ADR-0008](adr/0008-local-and-cloud-asr.md)）；具体协议、提供方、语言、数值预算和凭据实现待选。以下接口语义是草案，不是冻结的SDK代码。

## 已确认的云接入：BYOK

用户在Q8选择[自带服务商Key](adr/0009-cloud-asr-byok.md)，云识别费用由用户直接承担。首版不提供自有云账号/额度后台，也不在安装包或插件里嵌入维护者共享Key。具体凭据存储/代理方式、提供商和错误呈现仍需细化。

## 云端厂家由用户选择（Q17澄清）

用户要求本地与云端都支持，并由用户自行选择云端厂家。设计如下：

- 云端识别作为一个插件包，内置**厂家表**：每家一个服务地址，内部按协议复用适配器。用户在设置中选择厂家、填写自己的Key（BYOK）。
- 第三方也可以按统一插件规范，以独立插件新增厂家；它们和内置厂家一样实现 `speech.asr@1`。
- 每家标注验证状态：**已用真实Key验证**，或**按官方文档接入、未验证**。未验证的厂家在界面上如实显示。
- 首版内置三家：阿里云百炼、火山引擎、OpenAI（Q17）。火山引擎与OpenAI的识别接口正在补查官方文档；每家都要用真实Key验证后才标“已验证”。

## 用户看到的两种运行方式

| 方式 | 需要准备 | 识别数据去向 | 必须说明的限制 |
| --- | --- | --- | --- |
| 本地 | 兼容运行时与模型 | 内置本地识别链路不把录音发送到云ASR | 初次下载可联网；占本机资源；准确性/速度须实测 |
| 云端 | 网络与合法服务凭据/额度 | 向用户选择并批准的识别服务传输音频 | 服务费用、区域/政策、限流、网络依赖 |

不将“本地”标签等同于完整应用无任何网络行为；模型更新、可选云能力、遥测与日志须分别定义。第三方原生插件是否能被系统层限制联网，仍取决于后续信任和隔离方案，不能只凭清单保证。

## 首次设置与切换

1. 显示本地/云的区别，并让用户选择，而不是默认并行发送给两者。
2. 选择本地后检查模型与运行时状态；选择云后检查服务配置和数据外发授权。
3. 配置不完整时显示未就绪及修复入口，不让听写“无反应”。
4. 选择和配置在任务创建时绑定；默认提供者更改对新任务生效，活动任务如何重启需明确操作。
5. 自动回退需要另行设计和授权，首版不得以“提升成功率”为由静默扩大数据去向。

## 共享契约的语义要求（草案）

- **提供者身份**：插件ID/版本、引擎/模型版本、实际运行位置和能力声明。
- **任务上下文**：任务/会话/录音标识、配置版本、取消与截止条件。
- **音频输入**：采样率、声道、编码、分块顺序/时间和结束标记；不能假设所有引擎接收同一种默认音频。
- **文本事件**：临时转录、最终转录和修订顺序可区分；缺少词级时间戳/置信度时标为不可用，不编造。
- **能力差异**：原生流式、VAD分句/非流式、语言/混说、标点、词汇表等分别声明；迭代器不自动代表原生流式。
- **结束与错误**：成功、取消、未就绪、认证/限流/网络、模型/格式错误有稳定分类；不把所有错误包装成一条“识别失败”。
- **资源与诊断**：能查运行/准备状态，停用时释放资源；诊断默认不需要完整录音或明文转录，具体留存政策另定。

这些字段尚未决定用TypeScript接口、JSON Schema、RPC或其他传输表达；传输选择不能改变语义。

## 本地生命周期

未安装模型 → 下载/校验 → 可加载 → 加载中 → 就绪 → 识别任务 → 空闲/卸载。

下载失败不导致程序整体不可用；模型损坏/不兼容与设备不足分开报错。停止下载、停止识别和卸载模型是不同动作。CPU/GPU路径与最低配置须实测，不由本机拥有4GB显卡推断普遍兼容。

## 云端生命周期

未配置 → 配置校验/授权 → 就绪 → 上传/识别 → 完成或失败/取消。

认证、额度、区域、限流、网络断连、服务响应格式错误分别归因。取消应停止继续录音/上传并忽略晚到结果，但不能保证服务商不计费或撤销已发生的处理。重试须考虑重复费用和提供方幂等支持，不无限重放请求。

## 统一UI，不伪装统一能力

- 无论提供方，开始/取消/最终提交的基本语义一致。
- 不支持临时转录的提供者显示等待状态，而不是用假的实时字流填充。
- 展示当前是本地还是云端；切换时说明需要准备的模型/网络/凭据。
- 提供者失败不应让桌宠拖拽、设置台和停止入口失去响应。
- 任务取消后旧转录不得提交到目标应用；是否已输入属于后续输入能力的状态，不由ASR猜测。

## 双路径验收矩阵（待补具体环境/阈值）

| 场景 | 本地 | 云端 |
| --- | --- | --- |
| 未就绪 | 缺模型/运行时有明确修复 | 缺配置/授权/额度有明确修复 |
| 正常识别 | 固定模型/样本可复现 | 固定服务/模型与配置可复现 |
| 运行中取消 | 不再产出可提交的旧结果 | 停止后续上传，丢弃晚到结果，说明费用边界 |
| 网络断开 | 已准备模型的识别不依赖云ASR | 不静默改用别的外发服务；可恢复且不重复提交 |
| 提供者切换 | 新任务采用新配置 | 同左；在切云前确认数据去向 |
| 资源/错误 | 无足够资源、模型损坏不冻结UI | 认证/限流/超时不冻结UI |
| 数据检查 | 内置本地识别链路无录音外发 | 仅发给批准目的地，不向无关插件广播 |

真实云路径在发布前需要使用合法配置进行端到端验证。没有凭据时可用fixture验证契约，但不能据此宣称真实服务已验证。
