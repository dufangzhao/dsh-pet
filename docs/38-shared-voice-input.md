# 共享语音输入

这一增量让网页和桌面设置台把明确结束的一段录音，经 Magpie 转写后送入同一个持续 Agent。它复用普通消息的回执、去重和换代规则；打字草稿独立保留。当前验收进度统一见 [M4 验收记录](../qa/fixtures/companion-voice-input/acceptance.md)。

## 准备

1. 连接已经启动的 Agent 服务。
2. 桌面首次使用时，在组件管理中确认并启用“麦克风采样”。信任源码与允许麦克风是不同的许可。源码改变或信任被撤销后，需要重新确认并启用；如果期望开关仍为开而实际状态已停，先关闭再开启。
3. 网页需要支持 AudioWorklet 的浏览器，以及 HTTPS 或本机回环地址。直接访问远端 HTTP 地址不满足浏览器录音条件。界面会在申请采集票据前说明这一限制。
4. 在语音设置中配置独立的 Magpie 网关、鉴权方式和 ASR 模型。当前实现支持 Magpie 转发的 MiMo 专用 ASR 协议；完整模型标识保留供应者前缀。当前环境发现过 `xiaomi/mimo-v2.5-asr`，它不是所有安装的默认模型。

先保存网关设置，再读取该已保存绑定的 ASR 目录；选择候选后明确保存。也可以手填完整模型标识。目录出现候选只表示可以配置这次尝试，不表示已验证推理权限或识别质量。

使用网关密钥时，通过服务允许写入凭据的受信网页入口配置。密钥是此语音提供者独立的进程槽，重启后需要重新提供；桌面不显示写入框，不从文字模型、DSH 或 AstrBot 搬运凭据。本机回环网关可按网关策略使用公开客户端标识。

## 录音与发送

- 点击开始后才申请录音；界面在开始前显示最长20秒及当前结束模式。
- 点击结束或到达20秒上限，会停设备、冲刷尾帧并等待真实确认，然后开始转写。
- “结束后直接发送”将最终文本作为一条普通消息提交；“结束后先预览”允许修改后明确发送。
- 录音和转写都有取消入口。取消不会提交这段输入，也不会替代普通消息发送后对前台推理或独立任务的停止操作。
- 设置台换页不会终止所属录音。切换连接、撤销来源或关闭窗口时，旧采集按原归属清理，不能改投新 Agent。

ASR 的结果响应丢失时，只读取同一票据的状态，不重新上传音频。普通消息回执未知时，原文重试复用原 commandId；修改文本则是新的消息。实际准入被拒时，未提交文本留在本地，不排队自动重发。

## 可见状态的含义

- 未配置：缺少模型或必要设置，不开始录音。
- 目录读取失败：显示当前失败，不把旧目录当作本次成功结果。
- 麦克风拒绝或不可用：只影响语音；文字服务连接不因此失效。
- 释放尚未确认：不假装已经干净，也不将部分音频交给 ASR。
- 转写失败或没有语音：不产生空消息。
- 上游网关鉴权失败：是语音提供者错误；与 Agent 服务令牌失效分开处理。

音频通过受限的二进制通道传输，最终进入消息历史的是文本。录音开始本身不会停止 Agent 当前思考、已有独立工作或播放。文本提交成功之后，遵循现有 Core 的正常输入与抢占规则。

本增量还没有包含 TTS、全双工通话或其他平台入口。真实模型、真实设备及平台差异的已验证范围，以验收记录为准。
