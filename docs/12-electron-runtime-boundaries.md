# Electron运行边界草案 v0.1

状态：Electron + TypeScript已确认（[ADR-0011](adr/0011-electron-typescript-desktop.md)）；插件信任已按DSH方案确定（[ADR-0012](adr/0012-dsh-style-trust-and-permissions.md)）；进程分工与UI框架仍是待定设计。这里不是正在运行的系统拓扑。

## 不将“统一插件”误解为“所有工作挤在一起”

统一清单、生命周期和能力契约可以映射到不同执行位置。逻辑上平级的插件，不一定共享JS堆、线程或OS权限。

## 建议职责边界

| 区域 | 主要职责 | 不应直接承担 |
| --- | --- | --- |
| Electron主进程/基础宿主 | 窗口、托盘、启动、受控系统入口、进程托管 | 长时识别/合成、任意第三方UI逻辑、模型下载阻塞 |
| 桌宠/设置渲染器 | 输入反馈、状态展示、角色与受控面板 | 直接读取全部凭据、任意OS输入、未经代理的本机能力 |
| 插件运行区 | 生命周期、能力注册/调用与业务任务 | 用自身声明替代宿主授权；默认拥有全部用户数据 |
| 重计算/原生工作进程 | ASR/TTS推理、必要的原生适配 | 决定全局产品权限、任意改变主界面 |

具体插件运行区是进程内还是独立宿主、哪些模块单独进程，需要按信任与资源成本选择，不预设每个小模块都单独开进程。

## 候选接口原则

- 对外SDK保持清晰的异步能力调用、任务/取消和事件语义；避免把数据库连接、宿主Context或其他插件私有对象直接交给扩展。
- 控制消息与大块音频/图像分开治理；媒体通道有结束、顺序、背压和取消。
- UI请求校验来源、类型和具体目标，不只按通道名放行；权限决定不由渲染器自己写一个布尔值。
- 一次任务绑定插件实例/配置和用户意图；重连不能自动恢复已撤回授权。
- 官方预装与第三方插件使用同一能力契约；信任等级与运行位置由宿主政策决定，不信任插件自报“trusted”。

这些不是已实现的跨进程SDK。具体消息格式、传输、序列化和资源句柄需后续细化。

## 三个不同层次的保护

1. **产品行为授权**：约束模型/功能通过官方接口发起的操作，如录音上传、文本注入、电脑动作。
2. **故障与性能隔离**：插件崩溃、死循环、模型忙时，能保持基本UI与管理可用。
3. **恶意代码访问隔离**：真正限制陌生插件绕过SDK直接读文件、联网或启动程序。

前两者并不自动实现第三者。Node进程、utilityProcess、node:vm、manifest权限声明都不能单独等同于安全沙箱。平台研究见[技术材料](../research/tech-platform.json)。

## Q11：首版插件信任策略（已决定）

**已决定（2026-10-24）**：按DSH方案，见[ADR-0012](adr/0012-dsh-style-trust-and-permissions.md)——可信插件、权限预设、一次性审批、审计，对应下面的A。B保留为将来开放陌生第三方插件生态时的备选。

### A · 可信插件优先，明确不宣称恶意插件沙箱（建议）

首版以官方/自开发/用户明确批准信任的插件为主要支持对象；重计算和易失稳任务做进程隔离，所有走SDK的操作仍受宿主策略校验。陌生第三方代码不默认启用；安装/加载前说明它可能具有普通本机程序级访问。

- 优点：贴近成熟桌面扩展常用信任模式，能较快复用Node/原生生态并交付实用闭环。
- 代价：不能保证恶意插件不绕过SDK读文件或联网；权限页不能伪装成已经提供强制OS沙箱。
- 仍需做：来源/版本与安装脚本检查、显式信任、依赖清理、故障隔离、凭据保护、模型操作授权和停止入口。

### B · 首版同时建设受限插件运行环境

为符合SDK限制的脚本插件提供受限运行环境，只能通过宿主代理获得批准能力；需要原生库/独立可执行程序的插件另设高信任模式，不假装可以自动把任意npm/原生代码安全沙箱化。

- 优点：更适合接入未知第三方脚本，将权限契约变成可强制的访问边界。
- 代价：运行时、异步桥接、可用依赖、UI隔离、安装流程和安全测试显著增加；不能直接把进程隔离当作已完成。
- 需要验证：文件/网络/进程访问实际被限制、代理参数/目标校验、侧通道与资源耗尽、无法支持的插件能明确拒绝。

两种路径都保持逻辑单层插件标准。A不意味着取消正常操作授权；B也不意味着高信任原生插件没有系统风险。

## 版本与平台验证项

- 固定Electron/Node版本后再核对原生扩展ABI、external buffer等运行约束，不能只说支持N-API就算兼容。
- 核对所用凭据API在该版本的实际可用性，不直接照搬其他版本示例。
- 听写在设置窗口关闭、桌宠隐藏、设备切换和休眠恢复时的行为要实测。
- 主线程、渲染帧、工作进程和外部服务分别测量，不将网络等待伪装成UI卡顿或反过来。
- Windows真实输入与模型/音频依赖验证在用户允许原型后进行；当前不执行。
