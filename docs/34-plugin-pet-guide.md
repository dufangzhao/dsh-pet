# 插件式桌宠：使用与扩展

## 当前结构

应用继续采用 DSH 式统一插件宿主。Cortico0.2.7 是普通智能体插件，负责唯一的智能体循环、会话、事件记录和工具调用；Electron 负责窗口、原生输入、音频、凭据与授权适配。新增能力不需要另起一套宿主。

开始、人设、装扮、对话、语音输入分别由五个页面插件贡献。设置台根据当前已激活贡献生成导航；停用、故障或移除会撤下对应页面，扩展与关于保留恢复入口。桌宠和设置台编辑同一份偏好，阅读同一份日常记录。

## 使用

双击根目录[启动桌宠.cmd](../启动桌宠.cmd)，或开发时运行 pnpm dev。随应用构建的基础桌宠与页面按内容指纹启用；被用户停用的页面和智能体会保留选择。改动过的来源需要重新确认。

桌宠第一次出现时可直接通过气泡选择、输入并保存名字、配色、语音与回应方式，也可以稍后继续或从引导入口重播。无 Key 的离线脚本体验明确标注；本地 ASR 使用真实的已有模型。Key 经系统加密凭据代理保存，不进入提示词、配置或互动记录。开始页的“保存并开始”会实际测试连接，成功后才切换到该模型并继续响应；失败会显示原因，已经保存的模型和 Key 会保留。

设置台提供集中编辑：人设中保存完整正文，并查看实际系统前缀的名字/表达、人设和桌面说明各段；显示已保存、待生效、已生效或应用失败。提示词在当前处理批次结束后由 Core 重载，收到确认才报告生效；失败可重试，同一次失败不会被误认为已经应用。输入草稿在冲突和失败后保留。

装扮使用两种原创形态、四种配色与三种大小，另有显示、置顶、拖动、减少动画和语音选项。日常聊天、实际触碰与已显示的表情进入同一条时间线；更早记录通过 Core 游标分页读取。清空会清除 Core 的会话/事件数据，旧 Demo 数据只作为一次性迁移来源保留，不再持续写入，也不会在清空后自动复活。

语音最长20秒。只有主动开始录音才申请麦克风；可以跨页查看状态并结束或取消。结束后使用所选本机模型识别；关闭自动发送时先保留识别文字。取消不会把未完成音频送去识别。缺模型或权限会说明原因，不自动转云端。

权限确认优先显示在桌宠气泡，设置台的权限与数据页读取同一请求。选择与具体实例、任务和权限指纹绑定；旧选择不会批准新请求。云端模型使用询问策略，本机预设不会被拿来代表网络授权。

开发构建更新后，需要先从桌宠菜单或托盘选择退出，再运行启动器。关闭设置窗口不会结束后台主程序，重复启动会复用正在运行的实例。若更新后只剩扩展等恢复栏目，应先完全退出旧实例，再用原有资料重新启动；不需要清空配置或历史。

## 开始页

本轮按 Coopanion0.2.10 源码复刻公共设置外壳与“开始”栏，保留本项目的角色和品牌。其他页面保持已有功能，后续逐栏对齐。

连接模型提供15个服务分组；通义千问、Kimi、智谱和MiniMax的国内/国际平台各自保存 Key。选中厂商是草稿，“测试连接”检查已保存的当前连接。“保存并开始”保存后测试，通过才启用；测试期间配置发生变化会提示重新确认。ChatGPT使用系统浏览器登录，授权及刷新令牌仍由同一个加密凭据代理管理；登录失效后提示重新登录。

“我的桌宠”先显示可交互预览，再提供原生显隐与装扮入口。预览聊天与桌面气泡走同一条会话和记录；表情画到可见帧后才记录。使用向导会显示桌宠并暂时收起设置窗口，可从桌宠菜单重新打开。

“界面配色”提供三套内置方案、浅色/黑夜/跟随系统、36项调色及自定义方案。试色实时预览，保存才保留；离开页面撤销未保存试色。自定义方案的明暗变体独立保存，删除需4秒内再次确认。侧栏和编辑器使用同一份主题记录；旧主题选择自动迁移。侧栏运行控制暂停真实Core，暂停期间不接受新的聊天或录音。

任务运行详情和“停止全部任务”放在扩展页，保留原确认流程。

## 开始栏设计评审

双击[Start-Design-Lab.cmd](../Start-Design-Lab.cmd)打开独立Electron评审入口。可在并肩工作台、模型接线台、从连接到见面、桌宠在场、三页工作簿与基准间切换；[对照图与取舍](../qa/screenshots/start-design-lab/comparison.md)便于先比较。评审使用独立资料目录，默认展示并肩工作台只作为起点，普通启动仍用原资料和基准。

五版使用相同的已连接动作，切换不会重开录音或清掉模型/Key草稿；Key草稿只在内存。关闭整个配色工作区撤回未保存试色。选择生产版后再针对选中方案做最终收敛。

后续栏目或桌宠气泡可调用[replicate-then-redesign](../.agents/skills/replicate-then-redesign/SKILL.md)：先识别当前是否已有验收证据，补齐功能与界面复刻、冻结真实动作，再基于功能设计差异方案和验证；不会要求把已验收的复刻重新做一遍。

## 实现来源

“开始”栏的已列主流程已连接真实宿主动作，后端采用独立适配实现，并沿用本项目的插件架构。来源关系如下：

| 层 | 实际来源与职责 |
| --- | --- |
| 智能体循环、会话、工具执行 | 直接复用MIT的Cortico0.2.7，经本项目普通插件接入 |
| 插件生命周期、任务、权限、版本配置、加密凭据 | 本项目既有宿主与适配，不另建第二套 |
| 模型保存/实际探测/启用、OAuth与刷新、显隐/向导 | 本项目实现；对齐参考交互顺序及服务协议，保留本项目权限和CAS语义 |
| 设置界面及交互顺序 | 以Coopanion0.2.10为参考独立实现React展示；保留原创角色与品牌 |
| 界面主题 | 浏览器端同一UI记录与试色事务，不是另一项远程后台服务 |

这不等于完整复制Coopanion后端。当前“管理模型扩展”进入既有插件管理；参考的任意端点高级编辑器没有在本步搬入。真实账号登录和付费服务在线可用性尚未实测；已通过的证据范围统一见[QA状态](../qa/plugin-application-status.md)。

## 普通插件与模型接口

统一配置身份是 pluginId + instanceId；运行权限额外绑定 generation。主要接口为：

| 接口 | 用途 |
| --- | --- |
| app.profile@1 read/change | 同源人设与外观读取、版本检查后的配置变更 |
| agent.conversation@1 | Core 日常输入、状态、历史、提示词重载与互动回执 |
| llm.responses@1 | 完整模型 Generation、工具调用、实际用量；模型插件内使用凭据代理 |
| SDK config.get/save | 本插件配置快照与受任务/权限约束的自身配置保存 |
| SDK dataDirectory | 宿主分配的本插件持久目录，仅随声明的 plugin-data 能力交付；不代表任意文件权限 |

Cortico World 的 configure_pet 工具通过 app.profile@1 修改允许的偏好，仍要通过自己的配置权限和 CAS。模型和 UI 没有原始宿主、凭据读取、任意 IPC 或跨插件配置写入入口。新增工具、提供者和页面沿用同一 manifest、来源检查与生命周期。

页面使用既有 panel 贡献，其 entry 是公开 Cortico WebUiPageManifest JSON，包含 id/kind/label/availability/panels/configGroups 等数据。复杂自有浏览器扩展仍需单独的受控集成，不能从 manifest 任意注入脚本。外部页面的普通配置使用本插件 schema；按钮来自同 owner 已声明 command，经受监督任务执行。外部贡献不能冒用应用内置视图。声明的页面文件与 runtime/ui/worker 入口一起参与来源指纹，编辑后旧指纹失效。

插件作者的基础契约见[统一插件模型](adr/0010-unified-plugin-model.md)、[受控UI贡献](adr/0001-controlled-ui-contributions.md)和[SDK](../packages/plugin-sdk/src/index.ts)。本轮 Cortico 接入的正式决策见[ADR0014](adr/0014-cortico-agent-runtime.md)。

## 验证与限制

开发检查运行 pnpm check。真实原生验证分开串行执行：

- node qa/probes/cortico-e2e.mjs：实际 Electron 中的 Core/完整模型结果/工具/取消/重启。
- node qa/probes/cortico-plugin-e2e.mjs：普通插件发现、来源/配置权限、媒体、记录和代次生命周期。
- node qa/probes/application-backend-e2e.mjs：气泡流程、同源提示词/记录、语音开关、恢复、历史分页与外部页面动作。
- node qa/probes/application-model-e2e.mjs：隔离脚本模型经真实 Core 和配置审批执行或拒绝变更。
- node qa/probes/coopanion-start-ui-e2e.mjs：当前开始页的真实窗口、模型拒绝路径、主题、预览、显隐和重启。
- node qa/probes/start-model-e2e.mjs：真实宿主中的模型连接、权限、版本冲突与恢复。
- node qa/probes/application-ui-acceptance.mjs：此前基础版本的完整气泡流程与公开 WAV 录音探针，当前界面以开始页探针为准。

测试只使用隔离本机资料与公开音频，不需要用户 Key 或付费调用。GUI 探针中的 no-sandbox 仅为已记录的本机测试例外，不构成 OS 沙箱保证；录音授权不使用自动同意标志。最终结果读取相应机器报告，不能把脚本存在或组件测试当成原生通过。

更新通知已提供实际状态与下载/安装动作适配器，可验证选择、进度、重试和稍后。目前没有本项目发布源或安装包，生产界面不伪造可下载版本；真实在线更新需发行条件就绪。
