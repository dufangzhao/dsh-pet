# 桌宠与网页共享同一个 Agent

桌面程序现在作为独立 Agent 服务的客户端。桌宠、设置台和服务自带网页显示同一身份、消息与任务；退出桌面不会关闭服务，也不会停止已受理的后台工作。服务启动和默认 Magpie 配置仍以[服务指南](35-text-agent-foundation.md)为准。

## 连接

1. 先由操作者启动独立服务，记下服务根地址和访问令牌。桌面不会自动寻找旧启动文件、账号或凭据，也不会替你启动服务。
2. 打开设置台的「开始」，填写服务根地址，例如明确配置的局域网地址或 HTTPS 地址。地址不带 API 路径、用户名密码、查询参数或片段。
3. 点击「输入令牌并连接」，输入该服务的访问令牌后提交。地址会保存；令牌只保留在桌面 Main 进程内，退出后需要重新输入。更改地址、取消令牌输入及提交时，输入框都会清空。
4. 连接成功后核对服务里的助手身份与地址。在线时可用「更新连接或更换令牌」显式切换；连接中或退出旧连接时不重复提交。

访问令牌是服务的操作者凭据，权限范围与该服务当前接口一致，不是新增的多用户配对票据。桌面允许操作者明确选择 HTTP 或 HTTPS 目标；只应填写你准备使用的服务。模型网关 Key 的本机输入限制没有因此改变，桌面不会转发该私密写入接口。

地址表单使用起稿时的配置版本。若另一处更改了地址，草稿会保留，并提示读取新地址；本次保存自己的版本变化不会被误报为外部修改。

## 对话与任务

- 桌宠输入框和设置台「对话」发送到同一服务。界面根据真实回执确认受理；结果不明确时保留同一命令标识进行显式重试，避免重复效果。
- 近期任务显示真实状态、结果和文件。单任务停止只针对选中的任务；「停止这次回应」只作用于当前前台生成，不等于停止所有后台工作。
- 保存产物会打开系统文件选择器。路径留在 Main，桌面验证下载字节后再发布文件；取消选择不会产生目标文件。
- 断开后保留最后确认的内容和时间，未结束的任务显示未知。重连重新读取服务事实，不重放发言、旧任务或设备声音。
- 桌面退出后，独立服务仍能继续任务。下次启动时地址仍在，重新提供令牌后读取同一份服务状态。

## 身份、本机外观与模型

「人格」页面读取服务拥有的名称、人格和修订号。本阶段不提供人格或长期记忆编辑；这些属于下一阶段。旧桌面历史、人格和凭据不自动导入服务。

窗口、SVG 呈现、主题和受支持的音频控制仍由本机负责。本机外观保存只修改允许的呈现字段，不修改服务人格或创建对话。旧本地 Core、模型/OAuth 和语音输入恢复流程不会在新的共享组合中启动；未挂载的历史设计材料和源码仍保留。

设置台复用已有模型配置表单，可以保存非秘密设置并显式测试；不会因为填写或保存就暗中测试。模型 Key 只显示来源和状态，仍需在服务宿主机按服务指南配置。模型表单及其主题样式只加载到设置台，不进入透明桌宠窗口。

## 验证范围

当前阶段在实际 Linux Electron45 上使用生产 Main、preload、两扇文件窗口与独立回环服务验证。此前环境缺少系统图形库，QA 使用私有工具目录；其 Electron 仅调整本地库搜索路径，产品工作进程仍使用原有精简环境。`--no-sandbox` 是测试环境条件，不表示操作系统沙箱已获验证。

原生基线、真实连接表单/目标切换、三端消息 ID、后台工作/退出重连、定向停止、系统保存/取消、来源停用、最小窗口和隔离资料保留均已有分项证据；完整工作区门禁也已通过。它们来自分开的隔离场景，不宣称一次全量运行。Windows 原生窗口合成、语音与快捷键仍需真实 Windows 设备验证。详细范围由[阶段验收记录](../qa/companion-desktop-acceptance.md)统一维护。原来已停用的4120试用服务及其资料保持原状。
