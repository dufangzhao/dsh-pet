# Windows首发，保留其他平台的适配边界

首版正式支持Windows，其他平台后续再评估。业务与能力契约不应直接绑定Windows API，但“保留接口”不代表承诺首版macOS/Linux可用。

系统级语音热键、文字输入、截图、窗口、鼠标键盘、安装与更新均需要平台专属验证；集中在当前可验证的Windows环境，更适合先交付完整实用闭环，而不是把跨平台界面能打开视为全功能支持。

## 后果

- 首版不承诺macOS/Linux发布包或功能可用性。
- 插件要声明支持平台；不支持时明确禁用或提示，不伪造成功。
- 通过平台适配器隔离业务与系统能力；不要求首版实现全部平台后端。
- 具体Windows版本、CPU架构、最低配置和支持应用矩阵尚未确定。
- 桌面框架、原生语言和安装器尚未因此选定。
