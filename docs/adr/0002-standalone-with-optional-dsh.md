# 作为独立桌面应用运行，DSH为可选集成

本项目是独立桌面应用。普通用户不需要安装或启动DSH即可使用已实现的产品能力；DSH可作为以后通过适配器/插件接入的可选后端或工具来源，而不是必需运行时。

用户希望面向不同用户提供完整设置台和可定制扩展。强制依赖DSH会耦合安装、生命周期、版本和授权，因此放弃“仅作为DSH插件/前端”的产品路径。

## 后果

- 项目需要拥有自己的运行状态、配置、任务/会话和插件管理，具体实现仍可复用合适框架。
- 独立运行不等于完全离线，不等于自带所有模型，也不排斥受控的本地sidecar或云服务。
- DSH集成是否进入MVP尚未决定；没有DSH时不应出现核心流程无法启动的硬依赖。
- 不隐式启动或安装DSH，也不默认继承其账号、密钥、订阅或电脑权限。
- 接入时验证实际可用接口、版本协商和授权语义，不把内部接口当稳定公共契约。
- 此决定不选择Electron/Tauri、Cordis/Cortico、fork策略或许可证。
