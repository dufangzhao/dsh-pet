# 本项目自有代码采用MIT许可

用户明确选择MIT，而不只是保留“MIT/Apache待选”。本项目自有代码与原创文档采用MIT，允许在遵守保留许可声明等条件下商业使用、修改和分发，包括闭源二开。

该选择有利于较低门槛的采用和扩展开发，但不保证第三方修改回流，也不赋予本项目重新许可他人代码或素材的权利。参见[根许可证](../../LICENSE)和[第三方材料边界](../../THIRD_PARTY_NOTICES.md)。

## 考虑过的方向

- AGPL兼容开源：可以进一步评估现行Coopanion的派生开发，但会引入不同的对应源码和组合兼容义务；本次未选择。
- 主程序保留闭源：可以只开放SDK/部分模块，但不符合本次明确指定的主项目MIT方向。

## 后果

- 现行Coopanion AGPL产品代码不作为默认直接fork/复制底座；可以借鉴交互并独立实现，或评估许可合适的基础框架。
- Cortico、Cordis等候选仍需按实际固定版本和依赖核验，MIT方向不等于已经选定框架。
- 原创SDK代码若属于本项目，沿用项目MIT方向；第三方插件和独立资源不自动继承该许可。
- 不默认发布到GitHub；远程仓库、公开性与发布策略仍待确认。
- 商标、模型权重、声线/录音、角色资产及外部研究材料分别管理。
