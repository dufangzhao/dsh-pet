# 本阶段仅参考Coopanion，不以其产品代码二开

保留Coopanion作为交互、设置台、产品行为和架构取舍的研究参考；本阶段不fork当前或历史版本作为产品底座，也不将其AGPL产品源码直接复制到本项目。继续保持已经确认的自有代码MIT路线。

用户在了解AGPL仍属开源、允许商业使用但有相应源码义务之后作出此选择。研究资料与已写评审仍然保留，它们不是产品代码复用授权。

## 后果

- 独立实现适合本项目的界面和能力契约，不为模仿参考项目而复制其所有功能或限制。
- 不要求所有基础设施从零编写；依照许可复用适合的框架、引擎和组件仍然允许。
- 角色、声音、模型权重等不能因为项目开源就直接随产品分发。
- 此决定只排除本阶段Coopanion产品二开，不自动锁定Cordis、桌面框架或具体版本。
- 如未来重新考虑二开，须显式复审许可、改造成本与已确认目标，并以新ADR替代；不静默改变当前路线。
