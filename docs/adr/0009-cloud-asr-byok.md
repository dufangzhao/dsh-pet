# 首版云ASR使用用户自带服务商凭据

云端识别采用用户自带服务商API Key（BYOK）模式，由用户直接向服务商承担使用费用。本产品负责适配、配置验证、状态与凭据处理，不在首版引入自有云账号、额度/计费或托管识别后台。

这不削减已经选择的本地/云双路径；云路径仍须实际可用。相较产品托管账号模式，BYOK减少服务端运营与成本风险，但需要做好首次配置说明和错误定位。

## 后果

- 不将维护者共享Key硬编码进客户端或插件包。
- 服务商Key与端点、插件身份及批准用途关联，安全存储/代理方式后续选定。
- Key/端点修改、鉴权失败、余额/额度不足等要有可行动反馈，不显示为笼统识别失败。
- 不把开源免费等同于云ASR服务免费。
- 产品托管云可作为未来扩展重新评估，不是首版工作；新提供者仍应遵守同一能力契约。
