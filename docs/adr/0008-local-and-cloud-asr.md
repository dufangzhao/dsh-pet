# 首版提供完整本地与云端ASR，由用户选择

首版听写同时提供实际可用的本地和云端识别路径，首次设置由用户选择。不能把云端或本地其中之一仅实现为占位接口或未来计划；mock提供者仅用于测试，不能代替该范围承诺。

用户选择了更广的首版覆盖，接受相应的配置、数据说明、错误处理和测试范围增加。每条路径先至少有一种经过验证的实现，不意味着首版集成全部供应商。

## 后果

- 提供统一但保留能力差异的ASR契约；任务创建时选定提供者与配置，不运行中静默换路径。
- 首次选择与之后切换要说明本地资源/模型准备和云端录音外发；不因本地失败而未经批准自动上传。
- 本地与云端的就绪、错误和取消状态都要真实呈现；离线、网络/Key错误等分别验收。
- 引擎、模型、语言、云端账号/费用模式及数据留存尚未选择。
- 该决定只针对听写ASR，不选择聊天模型，也不等于所有语音功能同时支持本地与云端。
