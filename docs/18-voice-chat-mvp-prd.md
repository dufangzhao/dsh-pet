# 首条闭环：跟桌宠语音对话 PRD v1.0

状态：已确认可开工（[ADR-0013](adr/0013-voice-chat-first-loop.md)）。标“暂定”的细节按用户规则“不确定先参考Coopanion”给出默认值，实现中可凭证据调整，调整需记录在[实现计划](19-implementation-plan.md)或新ADR中。

## 1. 目标

用户按说话键对桌宠说话，文字由本地或云端识别（用户自选），进入桌宠自己的对话；AI流式回答显示在气泡与对话面板中，随时可以停止。所有功能都以内置插件提供，用户可以停用或卸载。

首版成功标准：

- 在用户电脑上，用本地识别和至少一家云端识别，都能完成“说话 → AI回答”的完整一轮。
- 识别和AI回复进行中，桌宠仍可拖拽，停止随时有效。
- 停用或卸载任一内置功能插件后，其余部分仍正常工作，其入口与资源被清理。
- 达到[实现计划](19-implementation-plan.md)中的性能初始目标，或记录未达到的原因。

## 2. 首版范围

| 模块 | 首版内容 |
| --- | --- |
| 桌宠窗口 | 透明、无边框、置顶，显示时不抢焦点；角色可拖拽；空白区域鼠标穿透；原创极简角色；状态：待机、倾听、思考、回答、出错 |
| 气泡 | 识别中的临时文字（模型支持时）、AI回复、错误与修复入口 |
| 说话键 | 一个键两种用法：长按为按住说话，松开结束；轻点为持续说，再按一次结束；持续模式静音过久自动结束 |
| 语音识别 | 本地：sherpa-onnx，SenseVoiceSmall与中英双语流式模型，实测后定默认；云端：阿里云百炼、火山引擎、OpenAI三家，用户自选，自带Key；普通话加中英混说 |
| AI对话 | 模型服务插件：厂家表加协议适配器，先做OpenAI兼容协议；默认DeepSeek（暂定，参照Coopanion）；自带Key；流式回复；停止；对话历史本机保存、可清空；人设（系统提示词）可编辑 |
| 对话面板 | 历史、流式回复、停止、文字输入（不说话也能聊） |
| 设置台 | 开始、桌宠、语音输入、模型、插件、权限与数据、关于 |
| 插件管理 | 内置插件列表、状态、停用与卸载、权限声明；少量基础模块受保护 |
| 权限 | 权限预设与一次性审批（录音、向云端发送音频与对话内容）；审计记录 |

## 3. 不在首版

朗读与TTS、音色制作与克隆、跨应用听写插件、看屏幕、电脑操作、角色制作工具、长期记忆、DSH桥接、自动更新、代码签名、匿名统计。它们按[路线图](19-implementation-plan.md)后续加入，都以插件形式实现。

## 4. 主流程

1. 按下说话键：立即进入“倾听”状态，桌宠与托盘显示录音标识。
2. 长按：松开即结束录音。轻点：持续说话，再按一次结束；静音超过设定时长自动结束（时长暂定，可调）。
3. 识别中：所选模型支持临时结果时，气泡边说边显示；否则显示“正在听…”。
4. 录音结束：定稿文字作为一条用户消息发给AI（暂定，参照Coopanion识别后直接交给角色；设置中可改为“先放进输入框，我确认后发送”）。
5. 思考 → AI流式回复，显示在气泡与对话面板 → 回到待机。
6. 停止：停止按钮或Esc取消当前回复；回复进行中再次说话，先停止当前回复（暂定）。

## 5. 状态与用户操作

| 状态 | 用户看到 | 可执行操作 |
| --- | --- | --- |
| 未就绪 | 缺什么：模型未下载、未填Key、麦克风不可用、未授权 | 一键进入对应设置修复 |
| 待机 | 角色待机 | 说话、打字、打开设置 |
| 倾听 | 录音标识；持续模式另有标识 | 结束（松开或再按）、取消 |
| 识别中 | 临时文字或“正在听…” | 取消 |
| 思考 | 思考动画 | 停止 |
| 回答中 | 流式文字 | 停止 |
| 出错 | 出错环节（识别、模型、网络、Key）与下一步 | 重试、修改设置；不自动改用别的厂家 |

## 6. 异常处理

- 本地识别失败：提示原因，不自动改用云端（[ADR-0008](adr/0008-local-and-cloud-asr.md)）。
- 云端识别或AI请求失败：鉴权、额度、限流、网络、超时分别提示；不自动换厂家；可重试。
- 取消后晚到的识别结果或回复：丢弃，不出现在对话中。
- 麦克风拔出或被占用：结束本次录音并提示。
- 插件崩溃：其余功能可用；插件管理页显示失败，可重试或停用。

## 7. 数据与隐私（暂定默认）

- 录音只在内存中处理，识别后丢弃，不落盘。
- 对话历史保存在本机，可在“权限与数据”页清空。
- Key只经宿主凭据代理保存，不进配置文件和日志。
- 日志不含录音、转录全文、对话内容和Key。
- 不收集匿名统计（项目没有服务端）。

## 8. 首版内置插件

| 插件 | 职责 | 提供 | 使用 | 卸载后 |
| --- | --- | --- | --- | --- |
| 说话键 | 报告全局按键的按下与松开 | input.talkKey@1 | — | 只能用界面按钮说话 |
| 录音 | 麦克风采集 | audio.capture@1 | — | 无法语音输入 |
| 本地识别 | sherpa-onnx两个模型 | speech.asr@1 | — | 仍可用云端识别 |
| 云端识别 | 三家厂家表 | speech.asr@1 | 凭据 | 仍可用本地识别 |
| 模型服务 | 厂家表与协议适配器 | llm.chat@1 | 凭据 | 对话不可用，提示安装或启用 |
| 对话 | 会话、历史、人设、流式编排；对话面板与气泡内容 | chat.session@1 | llm.chat@1 | 桌宠只剩外观与设置 |
| 语音对话 | 长按与轻点判定，录音 → 识别 → 送入对话 | — | input.talkKey@1、audio.capture@1、speech.asr@1、chat.session@1 | 仍可打字聊天 |
| 默认角色 | 原创极简角色渲染与状态动画 | avatar.render@1 | — | 显示最简占位 |

受保护的基础模块（不可卸载）：插件管理、设置台框架、权限与审批、凭据代理、任务与事件、托盘与退出。

能力名与字段为示意，以[契约草案](13-plugin-contract-draft.md)为准，实现时冻结。
