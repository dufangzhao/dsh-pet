# 产品需求基线 v0.13

状态：需求发现中。以下“已确认”指方向和偏好，不意味着所列功能都进入第一版。

## 产品描述

一个以桌面角色为入口、以实用能力为重点、允许不同用户按规范定制的AI桌面助手。既要日常交互轻便，也要设置台可深入调整，并能支持开发者扩展。

## 重要歧义：先不要替用户做决定

- “语音输入”：是与桌宠说话、向其他应用听写、语音命令，还是均包含？它们共用ASR，但后续权限与流程不同。
- “音色合成”：是选现成声音、录音克隆、文字设计声音、训练声音模型，还是其组合？
- “制作角色”：是配置人设与导入外观，还是内置画图、Live2D绑定、3D捏人？
- “操纵鼠标”：是执行明确的点击/输入，还是自动观察屏幕并完成多步任务？
- “扩展性强”：Q1已确认能力 + 受控UI贡献点；首版具体入口、工作流开放程度和SDK实现仍待细化。见[ADR-0001](adr/0001-controlled-ui-contributions.md)。
- “类似DSH”：Q2已确认不依赖DSH运行；借鉴框架、兼容插件或可选桥接仍是不同决定。见[ADR-0002](adr/0002-standalone-with-optional-dsh.md)。
- “喜欢开源扩展”：Q3现已明确主项目MIT；不等于接受现行Coopanion的AGPL派生路线，第三方插件与资产不自动改为MIT。

## 候选用户闭环（还不是MVP承诺）

| 场景 | 一次完整体验 | 需要独立验收的边界 |
| --- | --- | --- |
| 语音聊天 | 开始录音→识别→提交对话→显示/播报回答 | 取消、打断、识别错误、回声、联网失败 |
| 跨应用听写 | 选定目标输入框→说话→预览或提交文字 | 焦点变化、原文保护、权限、密码框、管理员窗口 |
| 朗读 | 选择文本与声音→合成→播放→停止 | 声音可用性、流式排队、取消旧音频 |
| 音色制作 | 授权素材→创建/试听→保存音色→供TTS使用 | 权利、云上传、本地/云资产兼容和删除 |
| 角色定制 | 选择外观/人设/声音→即时预览→保存组合 | 外观资产许可、格式兼容、预览性能 |
| 屏幕问答 | 选择窗口/区域→采集→问答→结束访问 | 上传范围、敏感信息、过期截图、撤销 |
| 受控电脑操作 | 用户目标→观察→计划/授权→执行→回读 | 错目标、失败恢复、敏感动作、紧急停止 |
| 装插件 | 查看说明/权限→安装→配置→启用→使用→停用/卸载 | 兼容、依赖、故障、资源释放、数据去留 |

## 设置台：候选信息架构，不等于首版全部实现

- 开始/概览：当前角色、运行状态、引导、模型连通性和快捷入口。
- 角色与交互：形象、人设、声音绑定、大小、动画、气泡与不打扰设置。
- 语音输入：设备、触发方式、识别引擎、语言、模型下载、监听状态与听写目标。
- 声音与TTS：合成提供方、音色、试听、速度、音频队列；音色制作可作为独立工具。
- 模型与Agent：连接、能力、参数、任务策略、上下文与费用。
- 视觉与电脑操作：捕获范围、执行器、授权、最近动作、停止入口。
- 插件与资源：能力插件、界面扩展、角色/声音资源、版本、配置、启停与诊断。
- 数据与隐私：记忆、历史、导出/删除、密钥、遥测、日志留存。
- 高级/开发者：插件日志、能力注册、契约诊断、测试/调试和配置检查。

普通用户与开发者的复杂度应分层呈现；具体是否采用两个全局模式，仍待用户选择。

## 将“丝滑”转成可验收要求

以下为设计建议，精确指标尚待共同选择，不是已测性能。

| 维度 | 使用者的感受 | 验收应观察什么 |
| --- | --- | --- |
| 输入反馈 | 点击/按键后知道已收到，不以为卡死 | 输入到状态反馈的延迟；不能等模型返回才响应 |
| 动画与拖拽 | 推理/下载时角色仍能顺畅移动 | 帧时间、长任务、鼠标拖拽延迟和卡顿频次 |
| 状态连续 | 录音、识别、思考、说话、执行之间不闪跳或丢反馈 | 状态转换、队列顺序、过期结果丢弃 |
| 可取消 | 停止就是停止，不再继续播旧声音/点旧窗口 | 取消传递时间、停止后残留动作/音频 |
| 配置生效 | 哪项立即生效、哪项需重载一目了然 | 即时预览、保存失败回滚、重载范围 |
| 插件故障 | 一个插件慢/崩溃，不拖垮桌宠与设置台 | 故障隔离、超时、降级、单插件重启 |
| 常驻成本 | 不使用时不白占显存、CPU与麦克风 | 按需加载、后台降频、资源释放与休眠恢复 |

技术方向候选：UI与重计算分离、有界队列与背压、分段/流式输出、取消协议、插件级资源统计、按需加载、设置事务化。框架和进程形态尚未选择。

## 已知环境与边界

本机只读检测：Windows 11、i5-11400H、约16GB内存、RTX 3050 Ti Laptop 4GB；Node 24、Python 3.12、.NET 10 SDK、Git、pnpm已存在，未发现Rust工具链。

这只是当前开发/验证环境，不是产品最低配置，也不能据此承诺全部本地语音/视觉模型可用。Windows首发已确认；云端依赖、预算、其他平台后续计划和完全离线要求待选。

## 当前不作的承诺

- 不承诺任意应用全兼容听写、任意模型即时响应或任意插件可安全运行。
- 不把“插件清单”“独立进程”“MCP”“node:vm”单独当成安全沙箱。
- 不将第三方项目的截图、角色、声音、权重和代码视作同一许可。
- 不因为某种能力在调研中存在，就自动列入本项目MVP。
