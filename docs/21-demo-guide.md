# Windows 桌宠 Demo 使用说明

这个 Demo 可以键入消息，也可以在本机录音、识别为文字，再显示回复与桌宠状态。无 Key 时使用明确标注的离线脚本回复；本地语音识别使用真实模型。

## 启动与首次准备

1. 双击根目录的 [启动桌宠.cmd](../启动桌宠.cmd)。设置台会打开；明确启用原创桌宠后才显示桌面角色，停用后会隐藏。托盘提供显示桌宠、打开设置、停止和退出。重复启动会显示同一设置窗口。
2. 打开「语音输入」，明确选择一个已在本机的模型。SenseVoice 按整段识别；Paraformer 处理时可以给出临时文字。本 Demo 都是说完后结束录音再识别。初次没有暗设模型。
3. 回到「开始」的准备清单，点「按选择准备」。核对名称、版本、完整代码指纹与声明权限，勾选你确认的功能。信任和启用是独立操作；本地预设的复选框默认不勾。想使用本地功能时可明确选择该预设：允许麦克风、插件进程、能力调用、插件数据与只读资源，拒绝网络。
4. 等清单显示所需功能已启用后，在对话框键入并发送，或点「开始录音」。

来源信任与权限预设只对本次运行有效，重新启动需重新确认。选择的模型、回复设置、本机记录和内置移除标记会保存。当前模型使用项目已有的缓存；权重不随 Git 提交。缓存缺失或哈希不符会报错，不会自动下载模型或改用云服务。

## 对话与停止

录音最长20秒。说完点「结束并识别」；取消录音不会把未结束的音频送去识别。关闭「识别完成后发送」时，识别结果保留供编辑，按发送后才进入对话。阶段、临时文字与回复会同步到桌宠气泡。

「停止」会取消本次工作并丢弃晚到结果；已经完成的消息会保留。「清空记录」需要确认，只清除本机对话。历史最多保留最近20条，并限制文件大小。插件停用或来源撤销也会使相关任务停止。

内置功能可以停用、逻辑卸载，再从「权限与数据」显式恢复；恢复不会自动信任或启用。受保护的核心模块除外。

## 可选的真实 DeepSeek 回复

在「模型」中保存自己的 DeepSeek Key，再到「语音输入」选择真实服务。需要确认并启用「DeepSeek 回复服务」；其网络权限应使用逐次询问，因为本地预设会拒绝网络。每次实际访问都受相应网络与凭据权限控制。

Key 使用系统安全存储与凭据代理；设置台只查询密文是否存在，不回读明文。界面的“已保存”只表示密文存在，不表示 Key 或模型已验证。开发验收不调用付费接口；用户主动发送到真实服务时才会访问固定的 DeepSeek HTTPS 地址。没有自动云回退。

## 当前交付范围

这是本机项目构建的 Windows Demo，尚无安装包。原生自动验收用固定公开WAV的Chromium假设备跑真实录音API，不代表真人麦克风、说话键、完整实时识别或M0的250ms指标已通过。正常启动不带假设备参数，只在用户明确点击并通过权限后使用麦克风。

启动器遇到已确认的本机沙箱启动故障时会提示并使用本地兼容模式。该模式不提供操作系统沙箱隔离；来源信任针对本次代码包，权限控制针对受监督任务与适配器。

开发、构建与验证命令见 [项目说明](../README.md#开发检查)，验收证据与未完成项统一见 [Demo状态](../qa/demo-status.md)。
