# 桌宠气泡与默认授权

本轮按用户2026-11-03的新指令实施。视觉以提供的252×71暗色输入气泡为首要基准，浅色采用同一几何；保留自有蓝色角色。对Coopanion的参考限于可观察设计与前端专家核对的本地0.2.10弹出、逐字行为，不复制产品代码或资产。

## 交互与视觉

| 项目       | 当前实现                                                                           |
| ---------- | ---------------------------------------------------------------------------------- |
| 输入占位   | 252×71；实际轮廓246×60、18px圆角、2px细边与底部尾尖                                |
| 输入行     | 196×36，展开与44×28发送按钮，右上关闭                                              |
| 暗浅       | 共用几何，由现有设置主题的appearance选择对应视觉变量，无第二份主题存储             |
| 弹出       | 240ms，cubic-bezier(.34,1.56,.64,1)，从尾尖40%/bottom位置缩放.82→1                 |
| 收起       | 140ms ease-in，缩至.9并淡出；立即inert/aria-hidden、退出命中，再移除DOM            |
| 逐字       | 普通字50ms、句中标点180ms、句末320ms；按字素拆分，保留流式追加的已有进度和截止时间 |
| 减少动画   | 直接呈现完整正文，关闭立即完成；读屏获得完整正文，不逐字播报                       |
| 草稿与焦点 | 展开仍是同一textarea，Enter/ShiftEnter/IME语义保留，快速重开清除旧收起计时器       |
| 命中       | 只计算真实圆角表面与可见裁剪区；头像不画选中矩形，按钮保留键盘焦点                 |

实现入口：[PetComposer](../apps/desktop/src/renderer/pet/PetComposer.tsx)、[逐字时钟](../apps/desktop/src/renderer/pet/bubble-reveal.ts)、[样式](../apps/desktop/src/renderer/pet/pet.css)。普通回复和业务选项共享同一气泡语言，关闭显示不伪装成已回答或已取消后台工作。

## 专家与DeepSeek

前端专家负责组件实现，后端架构专家核对授权链。真实调用的DeepSeek-Flash CN路由为magpie/qoder-cn/dfmodel、max档，给出基于所提供尺寸描述的参数建议；它未审阅源码或截图。最终采用其240/140ms与标点停顿建议，并保留现有字素、定时器与减少动画实现，没有新增动效框架。首条Qoder路由未交付结论，已中止，未计作设计完成。

## 授权默认值

桌面通过已有统一来源注册入口，为首次登记的插件实例设置allow预设；应用启用路径不再覆盖为ask/local。已有正常配置无须迁移，所有声明内权限直接取得任务租约，不进入授权队列。手动策略修改、来源/声明校验、任务取消、代次失效和插件停用仍按原体系工作。

本轮只改变权限请求默认值，普通业务选择与首次引导仍由用户操作。预设存于既有会话权限内核，没有新增授权数据库、IPC或自动点击弹窗逻辑。
