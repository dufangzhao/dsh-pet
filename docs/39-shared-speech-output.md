# 共享语音输出（TTS）

TTS 是可选的桌面内置插件。启用后，它通过配置的 Magpie 模型网关，将同一个 Agent 新提交的正式助手回复交给桌宠播放。设置台负责配置和控制，网页自身不播放。本阶段已完成受控生产验收及一次明确授权的真实 TTS 验证，具体范围统一见 [M5 验收记录](../qa/fixtures/companion-speech-output/acceptance.md)。

## 配置与启用

1. 按[桌面连接说明](36-shared-desktop-agent.md)连接 Agent 服务。TTS 关闭时也可以先读取和保存远端声音配置。
2. 在声音设置中填写 **Magpie 网关地址**、鉴权方式、完整模型标识和预置音色。保留网关地址的完整路径；不要填写模型厂商的直连地址。
3. 先保存网关设置，再读取已保存绑定的模型目录。当前实现支持 Magpie 转发的普通 MiMo TTS 流式 PCM 协议。目录候选不等于实际推理已通过；模型不预填为可用。
4. 在组件管理中确认并启用“语音朗读（TTS）”。它默认关闭；旧的本机试听开关不会自动开启正式回复朗读。启用/停用意图按现有应用配置保存。

每台桌面客户端分别决定是否朗读。播放对象是该 Agent 的新正式回复，包括从其他文字入口引发的正式回复；推理增量、工具原始回执和进度通知不进入声音。启用、重连或重启时不补播过去的消息。

## 播放与停止

- 普通回复边接收边播放。长回复保留正文和顺序，必要时在内部做少量文本分段；不摘要、不截断，也不保存整篇音频缓存。
- 当前与待播合计最多四条正式回复。队列满或某条失败会给出错误，文字对话和已有工作仍继续。
- “停止朗读”停止当前及待播声音，但插件保持启用；后续新回复仍可朗读。停用插件才会关闭后续自动朗读。
- 本机音量与远端模型配置分别保存。音量在每条回复开始时取值，修改用于后续朗读；需要立即安静时使用停止入口。关闭本机主声音开关会停止并拒绝新的合成。
- 隐藏桌宠窗口不等于静音。切换连接、停用来源和退出时会按原归属清理播放资源。

准备设备、正在生成、正在播放、播放结束和资源释放是不同事实。失败后已经清理，不代表本条已完整播放。这里不提供人耳是否听见的确认。

## 网关鉴权与独立密钥

`local-client-id` 仅适用于允许项目公开客户端标识的网关。需要网关 Key 时选择 `gateway-key`；TTS 使用自己的进程内凭据槽，不从文字模型、ASR、DSH 或 AstrBot 自动搬运凭据，重启后需要重新提供。

桌面不提供写入 Key 的桥，网页本片也没有 TTS Key 表单。操作员应在 **Agent 服务所在机器**，通过现有受信的本机 HTTP 入口写入。请求同时需要 Agent 服务的 Bearer 令牌；它与要写入的 TTS 网关 Key 是两种凭据。

先 `GET /api/speech`，从 `value.providers` 选择目标 `providerRef`，读取其 `configRevision`、`credential.version` 和 `credential.writable`。确认当前网关地址/鉴权方式后，以这些基线调用：

```http
POST /api/speech/credential
Authorization: Bearer <Agent 服务令牌>
Content-Type: application/json

{
  "providerRef": "pet.tts-magpie/magpie",
  "expectedRevision": <刚读取的 configRevision>,
  "expectedCredentialVersion": "<刚读取的 credential.version>",
  "value": "<TTS 网关 Key>"
}
```

`value: null` 是明确移除 Key。接口要求回环 peer 和受信 Host/Origin；不能把远端桌面视图里的 `writable: false` 当作可写。配置或凭据版本冲突时，先重新读取并确认目标，不自动改成最新版本重发。凭据按完整规范化网关地址及鉴权方式绑定，切换目标会清除旧槽；响应不会回显 Key。

## 当前范围

首版使用普通 MiMo 预置音色；不包含音色设计、克隆、SAPI 数字语速映射、全双工或自动打断。所有合成请求都通过 Magpie 固定转发接口；网络结果未知时不重新合成、不重新领取音频、不切换提供者补播。已发送的上游请求是否停止计算或计费，不由本地停止回执保证。

部署和排查时，接口与生命周期的实现规则见[语音输出代码契约](../.trellis/spec/backend/shared-speech-output.md)，执行证据只维护在验收记录中。
