# M5 controlled speech-output fixtures

These helpers provide independent synthetic loopback HTTP/SSE fixtures. Importing them starts no listener or product/device/model action. They declare the reviewed MiMo wire expectation; Companion and desktop contracts remain in product source. Current integration results are maintained once in [acceptance](acceptance.md).

## Concrete fixture API

[controlled-magpie.mjs](./controlled-magpie.mjs) exports `startControlledSpeechMagpie(options)` and pure `inspectTtsRequest(input, expected)`. Importing it starts nothing.

```js
const peer = await startControlledSpeechMagpie({
  expectedUserAgent: actualTtsUserAgent, // explicitly supplied from the future real source
  expectedAuthorization: expectedSyntheticAuthorization, // optional; never retained in observations
  vendor: 'xiaomi',
  model: 'mimo-v2.5-tts',              // bare native wire model, not a saved logical ID
  voice: 'Mia',
  expectedText: exactSyntheticSlice,   // optional exact comparison, preserving whitespace/CRLF/Unicode
  frames: 4800,
  pcmChunkBytes: 4800,                // odd values intentionally cross PCM16 frame boundaries
  fragments: [29, 257, 1021],         // separate actual response writes, each yields the event loop
  mode: 'stop',
  holdFirst: false,
  holdTerminal: false,
  usage: true,
});
try {
  // peer.baseUrl is an actual random-port http://127.0.0.1:<port>/v1 listener.
  // Future product integration must use its actual declared source APIs.
} finally {
  const closed = await peer.close();
  // closed.listening === false, closed.openSockets === 0, closed.pendingHandlers === 0
}
```

The only peer endpoints are:

- `GET /v1/models?kind=all`: actual catalog JSON with ordinary MiMo TTS, design/clone/unsupported TTS, ASR and audio-chat fixture rows. These are synthetic test rows, not a claim about any deployed catalog.
- `POST /v1/magpie/native/<encoded vendor>/v1/chat/completions`: validates the exact request shape `{model,stream:true,messages:[{role:'assistant',content:exactSlice}],audio:{format:'pcm16',voice}}`, `Accept: text/event-stream`, JSON MIME, configured own UA and optional expected synthetic authorization. No generic URL, model routing or product transport API is exposed.

`expectedUserAgent` has no default, so the fixture does not guess the project's new TTS identity or impersonate AstrBot. The self-tests use `dsh-pet-speech-fixture/1`, solely a fixture-client identity. Native request body is bounded to 64 KiB and text to the reviewed 4000-code-point segment boundary. No trimming, normalization, instructions, tools, user-style message, seed, optimize-text rewrite or whole-WAV fallback is accepted by this expectation. If actual Phase 0 source refines the codec, reconcile the exact wire contract explicitly before integration rather than inventing a consumer interface.

Returned handles:

| Handle | Meaning |
| --- | --- |
| `baseUrl`, `nativePath`, `format` | Actual owned endpoint and declared synthetic codec facts |
| `firstRequest` | First validated native request, safe metadata only |
| `firstAudioWritten` | First complete PCM SSE event written by the peer; **not** a consumer/media/device ACK |
| `beforeTerminal` | PCM events written; terminal still gated when requested |
| `firstResponseAborted` | Actual response socket closed before finish; **not** remote vendor compute/billing proof |
| `releaseFirst(requestNumber?)` | Release first-audio gate for one request or all held requests |
| `releaseTerminal(requestNumber?)` | Release terminal gate for one request or all held requests |
| `snapshot` | Counts, sanitized catalog/native request observations, per-request write/terminal/abort facts and actual open resources |
| `close()` | Idempotent close of listener/sockets, await each actual socket close and handler settlement, return final safe snapshot |

Safe observations include route, own identity, auth **presence**, native model/voice/stream/format, body keys/byte count, text length/code-point count/SHA256, generated bytes, event/write counts and write/drain counts. They do not contain the raw authorization value, raw request JSON, canonical text or accumulated audio. `responseFinished` means Node's HTTP finish event; it does not mean audio was played. Network fragments can be coalesced differently by TCP/Fetch, so tests verify reconstruction instead of pretending write calls equal read boundaries.

## Synthetic PCM and response modes

[synthetic-pcm.mjs](./synthetic-pcm.mjs) exports `SYNTHETIC_PCM_FORMAT`, `syntheticPcm16(frames, frameOffset=0)` and lazy `syntheticPcmChunks(frames, chunkBytes=4800)`. The deterministic integer pattern is generated per bounded chunk. Raw bytes have no WAV header; **pcm-s16le / 24000 / mono is the declared fixture codec**, not an independently measured sample rate or speaker/device property. Odd byte-sized SSE audio blocks exercise a downstream one-byte carry. Whole long PCM is not retained by the peer.

| Mode | Controlled result |
| --- | --- |
| `stop` | Progressive PCM, natural stop, optional usage, `[DONE]` |
| `length`, `content-filter` | PCM prefix followed by the corresponding incomplete finish reason |
| `eof` | PCM then normal HTTP EOF without terminal |
| `done-without-stop` | PCM and `[DONE]`, no natural stop |
| `zero-audio`, `usage-only` | No PCM; stop or usage/`[DONE]` cannot establish successful speech |
| `odd-tail` | One extra PCM byte before stop |
| `invalid-base64`, `truncated-event`, `error-event` | Explicit malformed or error SSE after a prefix |
| `audio-after-stop` | Audio illegally follows natural stop |
| `oversized-event` | SSE data exceeds 1 MiB |
| `decoded-oversize` | A decoded audio event exceeds 512 KiB |
| `auth`, `forbidden`, `rate-limited` | Actual HTTP 401/403/429, fixed synthetic JSON body |
| `nonstream-json` | Actual JSON MIME instead of SSE; no protocol fallback |

`holdFirst` and `holdTerminal` independently gate actual responses in any applicable mode. Consumer abort cancels blocked writes/gates through actual socket close. First metadata/comments/usage do not count as audio. The fixture bounds generation to a QA resource range; it does not assert the provider's numeric maximum or change product limits.

## Integration observations still required after Parent freeze

These fixtures are not production/source/media/playback acceptance. Read the actual new contract/provider/service/Main/Pet declarations first; do not infer names from this README. After a Parent-authorized frozen build, retain runner/product hashes and prove the following separately:

1. **Source and event admission:** genuine optional default-off; old audition-true does not opt in; each formal assistant/say commit admitted once in FIFO order, including multiple commits inside one UI refresh; notices/reasoning/raw tool receipts excluded; enable/reconnect/epoch change does not replay history. Web remains text/ASR with zero TTS initiation/player; console controls only, Pet is the single player.
2. **Canonical text and segments:** exact full text with Unicode/CRLF/whitespace preserved; short replies one native call; long reply at most four service-authoritative segments, contiguous offsets and exact concatenation, one logical FIFO slot. Record exact per-request text hashes and ordering. No hidden retry, resynthesis, re-GET or fallback after unknown/partial failure.
3. **Actual SSE/media concurrency:** first decoded PCM reaches Pet before provider terminal; strict streaming parse and frame alignment; >8 media chunks plus writer.end/reader/status/HTTP EOF settle without a wait cycle. Native success must be stop plus audio and actual raw settlement, not EOF or `[DONE]` alone.
4. **Consume ACK and bounded playback:** Main at most one 64 KiB IPC chunk; Pet at most six scheduled blocks plus current-chunk remainder. ACK waits for actual bounded scheduling/ended capacity. Exercise 1-frame and 64 KiB short tails; partial chunk must not wait for a later chunk before ACK. Track produced/drained/received/scheduled/ended/released as distinct facts, with no human-hearing claim.
5. **Long audio/backpressure:** cumulative audio >2 MiB and full text retained, while actual owned buffers/node count remain bounded as total grows. Verify slow consumer propagates ACK → Main read → HTTP drain → media credits → native read. Intentional backpressure must not trigger producer idle; actual stalled consumption must stop and drain. Healthy >40/55/120-second progress must avoid old absolute timeouts under the actual new clock contract.
6. **Whole stop/disable/source/target:** immediately fence current and future segments, prevent segment 3 after cancelling segment 2, ignore late bytes/resume/ACK, close real contexts and join native reader/media/task/credential uses. Delayed actual cleanup stays pending; failed close is not released. Retired connection cannot borrow a new token or claim remote settlement; preserve unknown where authorization was already fenced. Stop speech must not stop Core/work/ASR or erase accepted messages.
